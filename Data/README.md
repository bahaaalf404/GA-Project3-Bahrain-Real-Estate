# Data

The competition data isn't included in this repo, because the Kaggle competition rules don't allow sharing it outside the competition.

The competition is private (invite-only for the GA DSB-PT4 class): [Rental Prices: Bahrain Real Estate Market](https://www.kaggle.com/competitions/rental-prices-bahrain-real-estate-market).

If you have access, download these files and put them in this folder:

| File | What it is |
|---|---|
| `property_data.csv` | training listings with `rent` (32,090 rows × 41 columns) |
| `test.csv` | listings to predict, without `rent` (3,566 rows) |

The notebooks read them from `../Data/`.
